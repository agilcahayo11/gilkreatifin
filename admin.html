Cadangkan & Pulihkan Data (Backup & Restore)

Ekspor data website dalam format JSON untuk arsip atau impor ke perangkat lain.

1. Unduh Cadangan Data (Export JSON)

Simpan salinan utuh seluruh profil, karya portofolio, dan artikel Anda ke dalam berkas .json di komputer.

2. Pulihkan dari Berkas JSON (Import)

Unggah berkas JSON cadangan untuk memulihkan seluruh konten situs Anda.

3. Kembalikan ke Pengaturan Default (Factory Reset)

Hapus seluruh data kustom dan kembalikan website ke data awal bawaan.
